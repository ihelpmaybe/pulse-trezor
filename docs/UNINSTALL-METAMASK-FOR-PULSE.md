# Uninstall MetaMask for Pulse — use Pulse Perch

**Product:** Pulse Perch = bag / send / approve / swap / Sites / sign on PulseChain without MetaMask.  
**Transport today:** Trezor → Suite → Connect 10 (hardware path; not a software HD costume).

## When you’re ready

1. Install / open **Trezor Suite** (Desktop or Web).
2. Run **Pulse Perch** (this desk / PWA).
3. **Connect** → confirm Allow in Suite → see your address match the device.
4. **Load full bag** on Pulse (369). Testnet (943) is for lab only.
5. **Sites** → Reown project id (free) → paste `wc:…` from PulseX / Piteas / HEX / ProveX.
6. Sign on Trezor. Read the clear-sign strip + device screen.

## Before you remove MetaMask

- Note any **watch-only** addresses you still need (Perch: Settings → Export watch JSON).
- Revoke old MetaMask approvals you don’t trust (Perch → Approvals → Scan / Revoke).
- Prefer **bridged USDC** (`0x15D3…`) for ProveX — not the inherited fork USDC.

## What Perch does *not* replace yet

- Fiat on-ramps inside the wallet (use ProveX / Bridge as sites).
- Every L2 / ETH portfolio cloud.
- Store-ready browser extension (lab MV3 exists; Sites + inject cover most Pulse dApps).

## Safety

- Never paste a seed into Perch, chat, or a “support” site.
- If Suite is down, Perch will say so — fix Suite; don’t use a fake unlock path.
