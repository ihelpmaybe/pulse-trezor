## For contributors

1. Read [AGENTS.md](./AGENTS.md) (or the copy in the repo you opened).
2. Work from that repo’s [TODO.md](./TODO.md).
3. Respect [TESTING.md](./TESTING.md) and [HELPFUL-NOTES.md](./HELPFUL-NOTES.md).
4. Push to a branch / PR; don’t force-push `main` unless owner asks.
